01 — The Problem

錄一段畫面， 不必先裝 一整套 軟體。

你要的通常只是：把操作留下來、在畫面上指出重點、把檔案交給別人。 這個官網給的就是一個檔案，AURA-REC.html。 Mac 與 Windows 用同一個。雙擊後由 Chrome 或 Edge 打開，不用解壓縮。

  • 臨時要錄。教學、操作過程、回報一個問題。為了這一支影片去下載安裝、登入帳號，太重了。
  • 畫面上要有記號。圈出按鈕、打一盞聚光燈、讓人看到剛剛按了什麼鍵。這些放在同一個畫面裡。
  • 錄完要馬上看。慢一點看、換個顏色、標一段循環播放、把這一格存成圖。不用再開另一個剪輯器。
02 — What You Can Do

這個檔，做得到這些。

／ 01 RECORD

錄下你選的畫面

整個螢幕、一個視窗，或一個分頁，由瀏覽器的分享視窗決定。要系統聲音，在那個視窗勾選分享音訊。麥克風是工作站裡另外一個開關，可以和畫面聲音混在一起。按下後先倒數 3 秒。瀏覽器會盡量要到較高的解析度與 60 FPS，實際大小跟著你選的那塊畫面。

／ 02 MARK

在畫面上指出重點

畫筆、矩形、聚光燈，顏色可以換。畫幅導引有 16:9、9:16、1:1。按鍵會浮在預覽上。圓形鏡頭可以拖位置。畫面周圍的光會跟著影片的顏色走。濾鏡有原色、賽博、黑白、暖調。播放可以 0.5x 到 2x。畫筆會進「導出精華截圖」的 PNG。

／ 03 KEEP

看完，把檔案留下

底下有影像條和聲音條。拖綠色起點、紅色終點，播放會在這一段裡循環。空白鍵播放或暫停，J / L 前後一秒。存檔時按「無損匯出片段」，下載的是這次錄到的整段 WebM。也可以匯入一支既有影片來預覽。

03 — How To Use

四步，錄完就存。

請用 Chrome 或 Edge。第一次開啟需要網路，用來載入字型與介面。

01 打開

雙擊 AURA-REC.html

到下載資料夾雙擊。瀏覽器打開後，中間是舞台，底下是時間軸。還沒有畫面時，按「開始選取並錄製」，或按「匯入既有影片剪輯」。

02 錄

選畫面，倒數，開始

瀏覽器會問你要分享哪一塊。要電腦裡的聲音，在那個視窗勾選。工作站底部的「麥克風收音」是你自己的聲音。倒數 3 秒後才寫進檔案。空白鍵再按一次就停止。

03 看

標一段，換個看法

停下來之後，拖時間軸。I 是起點，O 是終點，播放會在這一段循環。右上角換濾鏡和倍速。左上角的畫筆、矩形、聚光燈用來指出這一格在看什麼。

04 存

WebM，或一張 PNG

「無損匯出片段」把這次錄到的整段存成 WebM。「導出精華截圖」把目前這一格，連同畫筆，存成 PNG。檔案會進瀏覽器的下載資料夾。
