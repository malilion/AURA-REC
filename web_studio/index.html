01 — The Problem

告別瀏覽器錄影的 限制、卡頓與崩潰。

瀏覽器錄影受限於 Web 沙盒與權限：在 Mac 上永遠錄不到系統聲音、軟體編碼極耗 CPU 導致掉幀發燙、長錄影記憶體爆掉、更無法支援全域快捷鍵。

AURA REC 桌面工作站 深入作業系統底層，提供真正專業、穩定、不卡頓的原生錄影體驗。

  • 晶片級硬體加速。支援 Apple Silicon (VideoToolbox) 與 NVIDIA / Intel / AMD 原生編碼，4K 60FPS 依然極致輕巧省電。
  • 系統聲音 + 麥克風雙軌。完美擷取電腦內部播放的音效與麥克風聲音，會議、遊戲、操作教學完整保留。
  • 全域快捷鍵與視窗追蹤。隨時按 F8 暫停、F9 停止、F7 截圖；錄製視窗時，視窗拖移自動即時跟隨裁切。
  • 串流直出 MP4 / MOV。直接寫入硬碟不吃記憶體，防休眠保護，即使斷電錄影也不損壞。

03 — How To Use

四步，快速上手。

開箱即用，已內建執行環境與硬體加速驅動。

01 安裝

雙擊開啟應用

Mac 下載後拖入「應用程式」即可開啟；Windows 下載解壓後雙擊 AURA-REC.exe。介面自動適配暗色模式與高解析度螢幕。

02 設定

選螢幕、音訊與範圍

選擇整個螢幕、自訂框選或指定程式視窗。勾選麥克風與系統音效。一般文書電腦會自動選擇最省資源的畫質配置。

03 錄製

空白鍵或快捷鍵開始

按下後 3 秒倒數準備。F8 隨時暫停/繼續（暫停時間不計入總長），F9 停止，F7 隨時截圖。視窗拖動自動追蹤跟隨。

04 剪輯

無損修剪與匯出

錄完直接在清單雙擊播放或按「剪輯」。在時間軸標記起點終點無損裁切，或轉換為 9:16 直式短影音發佈至社群。
