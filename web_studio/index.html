01 — The Problem

告別瀏覽器錄影的 限制、卡頓與崩潰。

瀏覽器錄影受限於 Web 沙盒與權限：在 Mac 上永遠錄不到系統聲音、軟體編碼極耗 CPU 導致掉幀發燙、長錄影記憶體爆掉、更無法支援作業系統級視窗排除。

AURA REC 桌面工作站 深入作業系統底層，提供真正專業、穩定、不卡頓的原生錄影與後製剪輯體驗。

  • 晶片級硬體加速。支援 Apple Silicon (VideoToolbox) 與 Windows Direct3D 11 WGC / NVENC / QSV / AMF 原生編碼，4K 60/120FPS 依然極致輕巧省電。
  • 系統聲音 + 麥克風獨立多音軌。完美擷取電腦內部播放音效與麥克風人聲並寫入獨立音軌，後製調整音量互不干擾。
  • 快捷鍵、F6 塗鴉聚光燈與視窗追蹤。視窗取得焦點時按 F8 暫停、F9 停止、F7 截圖、F6 全螢幕塗鴉與聚光燈；視窗拖移自動即時跟隨裁切。
  • OS 層級隱私排除與可視浮水印（盡力而為）。錄影控制條硬體穿透隱形，自動模糊 LINE / 1Password 等敏感視窗，並支援 Lissajous 動態可視浮水印。
02 — What You Can Do

原生桌面版，九大旗艦能力。

／ 01 HARDWARE & MULTI-TRACK

晶片加速與獨立多音軌

支援原生 4K、2K、1080p 與 60/120 FPS。Apple Silicon VideoToolbox 與 Windows WGC / NVENC 硬體編碼讓風扇不狂轉。支援麥克風 (Track 1) 與系統音 (Track 2) 獨立多音軌封裝，直出 MP4 / MOV。

／ 02 SMART AUTO-ZOOMS & 0.5S CUT

智慧運鏡與 0.5s 極速無損裁切

自動偵測畫面動態焦點生成平滑推進特寫；配備膠卷故事板滑鼠即時刷屏 (Skimming)、雙聲道振幅波形軌，以及 I-Frame 智慧拼接架構，0.5 秒瞬間完成毫秒級無損剪裁。

／ 03 LIVE ANNOTATION & SPOTLIGHT

F6 螢幕即時塗鴉、聚光燈與波紋

錄影中隨時按 F6 喚出全螢幕透明畫布：支援 B-spline 平滑手繪畫筆、銳利指向箭頭、重點高亮框與動態跟隨聚光燈 (Spotlight)，搭配滑鼠點擊發光波紋與按鍵 HUD 藥丸條。

／ 04 AI SPEECH-TO-TEXT CAPTIONS

AI 離線語音識別與智慧字幕軌

支援 Whisper Metal GPU 加速與內建 0 依賴離線 Smart VAD，0.1 秒瞬間自動識別語音時間軸。支援時間軸字幕軌連動預覽、SRT/VTT 雙向匯入匯出與 MP4 軟字幕軌封裝。

／ 05 PIP VIRTUAL BG & BLUR

畫中畫 (PiP) 人像智慧去背與虛化

支援圓形霓虹泡泡與圓角矩形，內建 6 種背景處理模式：原始畫面、人像景深虛化（輕微/標準/強烈）、純人像去背透空、綠幕/藍幕扣像與極光虛擬背板，支援即時試看預覽。

／ 06 WINDOW EXCLUSION & PRIVACY

視窗隱私排除與敏感應用遮蔽

透過 OS 原生 API 讓錄影控制列對錄影畫面完全透明穿透；自動偵測 LINE、1Password、密碼與無痕視窗並套用高斯模糊、馬賽克或防窺盾牌，後製亦支援局部框選模糊遮罩。

／ 07 VISIBLE WATERMARK

智慧動態浮水印引擎

零外部相依性高解析度抗鋸齒浮水印渲染器，支援角落品牌簽名、錄影時間戳記、沿 Lissajous 曲線平滑移動之「動態巡航浮水印」、滿版斜紋網格與自訂 PNG Logo。

／ 08 STYLED FRAMES & SOCIAL RATIOS

風格畫框與社群畫幅 (16:9 / 9:16 / 1:1)

一鍵套用極光、薄暮、深海等 Recordly 風格桌布與擬真 macOS 視窗外框 (🔴🟡🟢)。秒級切換 YouTube 橫式、Reels/Shorts 9:16 直式模糊補位與雙遍調色盤高清 GIF 導出。

／ 09 I18N HOT-SWAP & AUTO UPDATER

四語系即時熱切換與自動更新

內建繁體中文、English、日本語、简体中文 4 大語系，免重啟一鍵即時無損熱切換；串接 GitHub Releases API 自動檢查新版本，並內建 macOS 官方公證 (Notarization) 腳本。

03 — How To Use

四步，快速上手。

開箱即用，已內建執行環境與硬體加速驅動。

01 安裝

雙擊開啟應用

Mac 下載後拖入「應用程式」即可開啟；Windows 下載解壓後雙擊 AURA-REC.exe。自動偵測系統語系並支援頂部 🌐 一鍵切換繁中 / EN / 日本語 / 簡中。

02 設定

選螢幕、多音軌與保護

選擇整個螢幕、自訂框選或指定視窗。可開啟獨立多音軌、PiP 人像景深虛化/去背，以及視窗隱私排除與可視浮水印保護。

03 錄製

快捷鍵與即時塗鴉聚光燈

按下後 3 秒倒數準備。錄影中按 F6 隨時開啟螢幕塗鴉與動態聚光燈、F8 暫停/繼續、F9 停止、F7 截圖，控制條對錄影自動隱形。

04 剪輯

AI 字幕、智慧運鏡與匯出

在剪輯工作站一鍵生成 AI 離線語音字幕、設定 Auto Zoom 智慧運鏡與局部模糊遮罩，0.5 秒極速無損裁切或匯出 9:16 短影音與高清 GIF。
